# UX principles

- Design for stressed users: answer “what is this, what does it mean, and what can I do next?” in plain language.
- Start mobile-first; keep primary actions reachable and tap targets at least 44 by 44 CSS pixels where practical.
- Target an approximately 18px body size for reading-heavy content, comfortable line height, short measure, and strong contrast.
- Use calm hierarchy, warm neutrals, restrained status colors, and persistent source context—not hospital-like chrome.
- Reveal technical detail progressively without hiding material caveats.
- Prefer semantic landmarks, native controls, keyboard support, visible focus, meaningful link text, and reduced motion. Target WCAG 2.2 AA.
- Make research printable, shareable, and understandable without color alone.
- Use no fake urgency, countdowns, fabricated availability, deceptive lead forms, or aggressive chat interruptions.

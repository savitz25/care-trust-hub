# NJDOH Home Health and Hospice service-area records request (copy-ready)

**To:** New Jersey Department of Health, Health Facilities

**Re:** Machine-readable Home Health Agency and Hospice counties-served export

The official Acute Care Facilities Search states that a Home Health Agency county search returns agencies physically located in the selected county. Counties served appear on individual facility listings.

Deterministic public GET URLs keyed by FacID are not available for those listings (ASP.NET search POST / session). This request does not ask anyone to bypass CAPTCHA, login, or rate limits.

Please provide a current machine-readable export (CSV/XLSX) of:

- NJDOH FacID
- NJDOH license number
- Facility name
- Official facility type (Home Health Agency, Hospice Care Program, Hospice Care Branch, Hospice Care – Inpatient)
- Physical location county
- Each published service county
- Service ZIP, if published
- Branch/parent relationship, if published
- Source as-of / RunDate

Office location and service area must remain separate fields.

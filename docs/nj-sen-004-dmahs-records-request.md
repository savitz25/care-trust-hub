# DMAHS / NJMMIS assisted-living identity records request (copy-ready)

**To:** New Jersey Division of Medical Assistance and Health Services / NJMMIS provider publications

**Re:** SFY 2026 Assisted Living listed-provider rate schedule identity fields

The published SFY 2026 listed-provider rate PDF contains provider name, printed subtype, and daily rate only. It does not print Medicaid provider ID, NJDOH license number, or FacID.

Please provide the current listed-provider schedule as CSV/XLSX with:

- Medicaid provider ID
- NJDOH license number and/or FacID
- Legal name
- Address
- Official subtype (ALR, CPCH, ALP)
- Listed daily rate
- Effective date
- Fiscal year

Do not include beneficiary information or other protected data.

Default unlisted ALP/ALR/CPCH rates should remain documented as default rates and must not be represented as listed participation.
